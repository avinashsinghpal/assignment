# Flask + MongoDB on Kubernetes (Assignment Submission)

This repository contains two components for the Kubernetes assignment:

| Directory | Description |
| :--- | :--- |
| `flask-mongodb-app/` | **Part 1 (Local Setup)**: Python Flask application with local virtual environment, baseline requirements, and MongoDB docker testing. |
| `flask-mongodb-k8s/` | **Part 2 (Kubernetes Submission)**: Production containerized Flask application, Kubernetes manifests (`k8s/`), automated deployment scripts (`deploy.sh`, `deploy.ps1`, `Makefile`), test logs, and architectural documentation. |

---

## Getting Started

To deploy, inspect, or test the Kubernetes submission:

```bash
cd flask-mongodb-k8s
```

Follow the complete instructions, architecture guide, and verification steps in the main documentation:
👉 **[flask-mongodb-k8s/README.md](flask-mongodb-k8s/README.md)**
